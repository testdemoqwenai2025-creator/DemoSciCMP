Quick Start Workflow

Get your docking simulation running in 5 simple steps.

1

Prepare Ligand

Convert ligand to PDBQT format with proper charges and rotatable bonds.

obabel ligand.sdf -O ligand.pdbqt --gen3d -h
2

Setup Receptor

Prepare receptor file and define search space/grid box coordinates.

python prepare_receptor.py --receptor protein.pdb --center_x 10.5 --center_y 20.3 --center_z -15.8
3

Configure Parameters

Select preset or customize exhaustiveness, num_modes, and energy range.

4

Run Docking

Execute AutoDock Vina with selected configuration.

vina --receptor rec.pdbqt --ligand lig.pdbqt --config config.txt
5

Analyze Results

View docking poses, analyze interactions, generate reports.

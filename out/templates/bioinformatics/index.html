Quick Start: Sequence Analysis Workflow

From FASTA files to phylogenetic tree in 5 systematic steps.

1

Data Import & Quality Control

Import sequences in FASTA/FASTQ format, perform comprehensive quality checks with FastQC, generate MultiQC reports, and trim adapters with Trimmomatic.

# Quality control pipeline fastqc raw_reads/*.fastq.gz -o qc_results/ multiqc qc_results/ -o multiqc_report/ trimmomatic PE -phred33 input_R1.fastq input_R2.fastq \ paired_R1.paired.fastq paired_R1.unpaired.fastq \ paired_R2.paired.fastq paired_R2.unpaired.fastq \ ILLUMINACLIP:adapters.fa:2:30:10 LEADING:3 TRAILING:3 \ SLIDINGWINDOW:4:15 MINLEN:36
2

Multiple Sequence Alignment

Align sequences using progressive methods with iterative refinement. Choose from MAFFT (speed), Clustal Omega (accuracy), or MUSCLE (large datasets).

# Run MSA with MAFFT (auto mode) mafft --auto --thread 8 --reorder input.fasta > aligned.fasta # Alternative: Clustal Omega for better accuracy clustalo -i input.fasta -o aligned_clustal.fasta \ --outfmt=fasta --threads=8 --force
3

Alignment Refinement & Trimming

Trim poorly aligned regions with trimAl or BMGE. Check for recombination signals with GARD. Assess alignment quality with Zorro confidence scores.

# Trim alignment automatically trimal -in aligned.fasta -out trimmed.fasta \ -automated1 -leavegaps # Automated gap handling # Check alignment statistics alignstat.py trimmed.fasta > alignment_stats.txt
4

Model Selection & Tree Building

Select best-fit substitution model with ModelTest-NG, then build maximum likelihood tree with ultrafast bootstrap support using IQ-TREE2.

# Build tree with IQ-TREE2 (automated) iqtree2 -s trimmed.fasta -m MF -B 1000 -alrt 1000 \ -T AUTO -pre output_tree # MF = ModelFinder (auto model selection) # B = Ultrafast bootstrap (1000 replicates) # alrt = SH-aLRT test (1000 replicates)
5

Visualization & Interpretation

Annotate tree with metadata (geography, host, time). Generate publication-ready figures with iTOL or FigTree. Interpret evolutionary patterns and divergence times.

# Visualize interactive tree # Upload output_tree.treefile to https://itol.embl.de/ # Or use FigTree for local visualization: # Convert to Newick with support values cat output_tree.treefile | treeviewer # Export as high-resolution figure # Recommended: SVG → PDF/ PNG at 300 DPI

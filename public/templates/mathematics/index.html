Quick Start: Symbolic Math Workflow

From problem statement to elegant solution in 5 steps.

1

Define Symbols & Expressions

Create symbolic variables, define functions, set up the mathematical expression to analyze.

# Initialize symbolic computation from sympy import * x, y, z = symbols('x y z') f = sin(x)**2 + cos(x)**2 # Define expression: sin²(x) + cos²(x)
2

Simplify & Transform

Apply algebraic identities, factor expressions, expand polynomials, rationalize denominators.

# Simplify expression simplified = simplify(f) print(simplified) # Output: 1 # Verify trigonometric identity
3

Differentiate & Integrate

Compute derivatives (partial, total), definite/indefinite integrals, find critical points.

# Calculus operations g = x**3 * exp(-x) g_prime = diff(g, x) # First derivative g_integral = integrate(g, x) # Indefinite integral critical_points = solve(g_prime, x)
4

Solve Equations

Find roots of polynomials, solve systems of equations, differential equations analytically.

# Solve equations equation = Eq(x**2 + 5*x + 6, 0) solutions = solve(equation, x) print(solutions) # Output: [-3, -2]
5

Visualize Results

Generate plots of functions, phase portraits, contour maps, and export to LaTeX/PDF.

# Visualize function import matplotlib.pyplot as plt import numpy as np x_vals = np.linspace(-5, 5, 400) y_vals = [g.subs(x, xv).evalf() for xv in x_vals] plt.plot(x_vals, y_vals) plt.savefig('function_plot.png', dpi=300)

Quick Start: Sequence Analysis Workflow

From FASTA files to phylogenetic tree in 5 steps.

1

Data Import & QC

Import sequences in FASTA/FASTQ format, perform quality checks with FastQC, and trim adapters.

# Quality control fastqc raw_reads/*.fastq.gz -o qc_results/ multiqc qc_results/ -o multiqc_report/
2

Multiple Sequence Alignment

Align sequences using progressive methods with iterative refinement for accuracy.

# Run MSA with MAFFT mafft --auto --thread 8 input.fasta > aligned.fasta
3

Alignment Refinement

Trim poorly aligned regions, check for recombination signals, and refine alignment.

# Trim alignment with trimAl trimal -in aligned.fasta -out trimmed.fasta -automated1
4

Model Selection & Tree Building

Select best substitution model, then build phylogenetic tree with bootstrap support.

# Build tree with IQ-TREE iqtree2 -s trimmed.fasta -m MF -B 1000 -T AUTO
5

Visualization & Interpretation

Annotate tree with metadata, generate publication-ready figures, interpret evolutionary patterns.

# Visualize with iTOL or FigTree # Upload treefile.tree to https://itol.embl.de/
